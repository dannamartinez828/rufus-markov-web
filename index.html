Una guía rápida

Cómo leer esta aplicación

Un estado es un punto de la línea temporal en el que puede estar Rufus: Aldea Kuvaq, Eliseo, Tiempo intermedio o Reinicio.

La matriz de transición muestra las posibilidades de pasar de cada estado actual (filas) a un estado siguiente (columnas). Cada fila suma el 100 %.

La propiedad de Markov significa que el siguiente estado depende solo del estado actual, no de todo el camino anterior.

Para calcular varios saltos se eleva la matriz a n y se aplica al estado inicial: vector inicial × matrizn.

Las probabilidades son supuestos de este modelo educativo, no datos oficiales del juego.
